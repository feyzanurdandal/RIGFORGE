# RigForge

## 📖 Proje Hakkında

RigForge, bilgisayar bileşenlerinin satışına yönelik geliştirilen modern bir e-ticaret web uygulamasıdır. Kullanıcılar ürünleri inceleyebilir, filtreleyebilir, sepete ekleyebilir, favorilere kaydedebilir ve sipariş oluşturabilir.

## 👥 Takım Üyeleri

- Ece Birick
- Feyza Nur Dandal

## 💻 Teknoloji Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- ASP.NET Core (.NET)

### Veritabanı
- Microsoft SQL Server

## ✨ Proje Özellikleri

- Ürün Listeleme
- Ürün Arama
- Ürün Filtreleme
- Ürün Detay Sayfası
- Sepet Yönetimi
- Favoriler
- Kullanıcı Girişi / Kayıt
- Checkout (Ödeme Simülasyonu)
- Sipariş Geçmişi
- Kullanıcı Profili
